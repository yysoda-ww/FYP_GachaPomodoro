[Overview]
Built as my Final Year Project to explore whether gamified rewards ccould make Pomodoro-style
productivity tools more engaging without punishing missed sessions, using gacha system instead of streaks, since streaks reset to zero on a single missed day. Validated through user testing with 7 participants across 22 test cases, achieving a 4.1/5 average rating and 95% test pass rate

[Features]
- Pomodoro timer system
- To-do list management
- Reward and currency system
- Character gacha system
- Custom character illustrations drawn by myself
